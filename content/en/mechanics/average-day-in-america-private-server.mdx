## How to Set Up and Configure Your Private Server

Purchasing and configuring your instance only takes a couple of minutes through the game hub. Roblox manages VIP servers on a monthly subscription model, meaning you can cancel at any time if you simply want to test custom mechanics for a single month.

### Step-by-Step Purchase and Creation Guide

Follow these steps to generate your first custom session:

| Step | Action Required | Details |
| :---: | :--- | :--- |
| **1** | Navigate to the Game Page | Open *Average Day In America* on the Roblox desktop app or browser. |
| **2** | Open the Servers Tab | Scroll past the description and badges to locate the **Servers** tab. |
| **3** | Click "Create Private Server" | If servers are free or require Robux, the exact fee displays here. |
| **4** | Name Your Server | Choose a distinct label (e.g., "Aim Training Ground" or "Fight Night"). |
| **5** | Configure Privacy Settings | Click the three-dot icon beside your server to open **Configure**. |
| **6** | Enable Join Permissions | Toggle "Friends Allowed" or generate an explicit private share link. |

Once generated, anyone with the direct URL or anyone on your Roblox friends list (depending on your toggled settings) can hop into the lobby instantly without taking up room on public leaderboards.

## Optimizing Server Performance and Reducing Ping

Like many physics-heavy Roblox titles, performance can degrade if an instance stays open for extended durations. Stray assets, abandoned vehicles, and high projectile counts can cause latency spikes. 

If you or your friends experience input lag or frame drops in an **Average Day In America private server**, use the checklist below to restore optimal performance.

### Performance Troubleshooting Table

| Issue Encountered | Likely Cause | Recommended Fix |
| :--- | :--- | :--- |
| **High Ping (>150ms)** | Sub-optimal host region allocation | Re-create or rejoin the server so Roblox spins up a closer data center node. |
| **Low FPS / Stuttering** | Cluttered vehicle/item physics | Use the server configuration dashboard to shut down and reboot the instance. |
| **Join Link Fails** | Expired or corrupted link token | Regenerate the server link in your Roblox configuration menu. |
| **Invisible Walls / Glitches** | Map streaming desync | Lower graphic quality slider down to level 4 or 5 temporarily to force asset reload. |

Regularly restarting your server ensures a clean physics engine slate, minimizing hit registration issues during competitive duels.
