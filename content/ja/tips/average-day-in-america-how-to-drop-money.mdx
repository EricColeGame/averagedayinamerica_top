## 基本メカニクス：現金のドロップと受け渡し

オープンワールドのサバイバル環境における現金の取り扱いには、常にリスクが伴います。保護された専用のプレイヤー間トレードウィンドウが用意されている一般的なRPGとは異なり、『Average Day In America』ではリアルタイムかつ物理化されたアイテムの挙動が重視されています。お金をドロップすると、地面の上に目に見える現金のオブジェクトが生成され、近くにいるプレイヤーなら誰でも即座に拾うことができます。

手持ちのウォレットを操作するには、以下の標準的な入力手順に従ってください。

| プラットフォーム / 入力方式 | アクションのトリガー | ドロップの実行 | 補足事項 |
| :--- | :--- | :--- | :--- |
| **PC（キーボード/マウス）** | インベントリを開く（`Tab` または `B`） | 現金アイコンをウィンドウ外にドラッグ / `Drop` をクリック | `Shift` を押しながらドラッグすると、指定した金額を入力可能。 |
| **PC チャットコマンド** | `/` キーでチャットを開く | `/drop [金額]` と入力（例: `/drop 500`） | セーフゾーンメニューの外部に立っている場合のみ有効。 |
| **コンソール（コントローラー）** | `方向キー下` / インベントリ表示 | ウォレットを選択 -> `X` / `Square` を押す | スライダー画面が表示され、任意の数量を指定可能。 |
| **クイックトス用キー** | ホットバーの割り当てスロット | 現金ツールを持った状態で `Backspace` を押す | 現在装備している額面をその場ですぐにドロップ。 |

コミュニティの報告によると、サーバーのpingが120msを超えると、ドロップコマンドに入力遅延が発生する場合があります。インベントリメニューを閉じる前に、現金の束が確実に地面へ落ちたか目視で確認してください。

## よくある現金のドロップトラブルと解決策

状況によっては、ゲームシステムによって通貨の受け渡しが完全にブロックされることがあります。仕様が壊れていると勘違いして混乱する初心者も少なくありません。多くの場合、これらの制限は不正対策のシステムロック、戦闘タグ、または [Roblox](https://www.roblox.com/) のコアエンジンに組み込まれた制限に起因しています。動的な物理エンジンでは、インタラクティブなアイテムを生成するために特定のプレイヤー状態が求められることがあるためです。

お金が地面に出現しない主な原因と解決策は以下の通りです。

| トラブルの症状 | 根本的な原因 | 解決策 |
| :--- | :--- | :--- |
| **「Cannot drop in this zone（このゾーンではドロップ不可）」** | 保護されたセーフゾーンまたはロビー施設内にいる。 | 通常のゲームプレイセクターへ移動する。 |
| **「Combat Tag Active（戦闘タグ有効）」** | 過去15秒以内にダメージを受けた、または与えた。 | 射線を切り、回復してタイマーが切れるのを待つ。 |
| **現金の束が出現しない** | サーバーの遅延、または該当チャンクのアイテム上限到達。 | 20〜30スタッドほど離れた場所に移動するか、別サーバーに入る。 |
| **ドロップ額がデフォルトの$0になる** | チャットコマンドの構文ミス。 | 記号を入れず半角数字のみ入力する（例: `/drop $100` ではなく `/drop 100`）。 |
| **ウォレットがグレーアウトしている** | 拘束、スタン、またはラグドール状態になっている。 | 復帰モーションが完全に終了するまで待つ。 |

プレイヤーの検証によると、リスポーン後にウォレットアイコンが反応しなくなるようなしつこいUIバグは、ゲームクライアントを再起動することで解決するケースが多いようです。

- **大金は銀行に預ける:** 武器、アーマー、当面必要なアイテムに使う分だけを持ち歩くようにします。
- **分割してドロップする:** 装備の対価として他プレイヤーに支払う際は、一度に大金を渡さず小分けにしてドロップします（例: $1,500を1回ではなく、$500を3回）。相手が約束通りアイテムを渡すか確認しながら進めましょう。

- **過密エリアを避ける:** スポーン直後の混雑地点は、スリやアイテムの横取りを狙う高速移動プレイヤーが潜む危険地帯です。

## よくある質問（FAQ）

### 『Average Day In America』でチャットコマンドが効かない場合、どうやってお金をドロップすればいいですか？
`/drop [金額]` のチャットコマンドが反応しない場合は、`Tab`（または `B`）でインベントリを開き、所持金のアイコンをクリックしてウィンドウ外へドラッグするか、画面内の「Drop」ボタンを選択してください。なお、操作を行う前に戦闘タグが解除されていることを確認してください。

### ドロップしている最中に他のプレイヤーにお金を盗まれることはありますか？
はい、あります。ドロップされたお金は地面に物理オブジェクトとして配置されるため、近くにいるプレイヤーなら誰でも回収可能です。横取りを防ぐため、必ず壁に囲まれた安全な場所で行うか、信頼できるチームメイトと密に連絡を取りながら取引してください。

### 一度にドロップできる金額に上限はありますか？
不正利用やアイテム増殖（dupe）を防ぐため、ほとんどのサーバーで1回の取引額に上限が設定されています。各サーバーのルールによって異なりますが、一般的には1つのコンテナあたり$5,000〜$10,000程度が上限です。これ以上の金額を渡す場合は、複数回に分けてドロップするか、銀行機能を通じた送金を行ってください。

### サーバーが再起動すると、ドロップしたお金は消えてしまいますか？
はい、消失します。地面に落ちたまま誰にも拾われていない現金オブジェクトは、サーバーのリセット、クラッシュ、またはエリアのチャンクアンロード時にすべて消去されます。お金を床に置いたまま放置しないよう注意してください。
