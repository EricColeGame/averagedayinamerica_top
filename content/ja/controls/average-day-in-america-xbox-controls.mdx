## 車両の操作方法とドライビングの基本

街中を走る状態から大排気量のモンスターマシンに乗り換えると、操作感がガラリと変化します。『Average Day In America』ではカーチェイスが頻繁に発生し、一瞬の操作ミスが命取りになります。

| 入力 | 通常の運転操作 | 戦闘 / タクティカル運転 |
| :--- | :--- | :--- |
| **右トリガー (RT)** | アクセル / 前進 | バーンアウト（停車中に RT + LT 同時押し） |
| **左トリガー (LT)** | ブレーキ / バック | リバースドリフトの始動 |
| **左スティック (LS)** | ステアリング操作 | 重心移動 / 空中での車体姿勢制御 |
| **A ボタン** | ハンドブレーキ / 緊急ブレーキ | コーナーでのパワースライド |
| **B ボタン** | 後方視点 / バックカメラ | クラクション / サイレン |
| **X ボタン** | ヘッドライト切り替え | 車内ラジオ局の変更 |
| **Y ボタン** | 走行中の飛び降り脱出 | 停車中の安全な降車 |
| **LB (左バンパー)** | ドライブバイ照準 / サブ武器 | ドライブバイ用武器の選択 |
| **RB (右バンパー)** | ドライブバイ射撃 | 撒菱（スパイク） / スモークの投下 |

### 高速カーチェイスを生き残る重要テクニック

- **ハンドブレーキ（Aボタン）は軽くタップする:** コーナリング時にAボタンを押しっぱなしにするとスピンしてしまいます。左スティックで舵角をつけながらAボタンを細かくタップすることで、失速を防ぎつつ美しいドリフト軌道を維持できます。
- **ドライブバイの精度を高める:** 敵車両を攻撃する際は、いきなり発砲せず、まず**LB**を長押しして照準を安定させてから**RB**で射撃しましょう。弾薬の無駄遣いを防ぎ、車の進路を真っ直ぐ保ちやすくなります。
- **緊急脱出の判断:** 高速走行中に**Y**を短押しすると飛び降りローリング脱出が発動します。落下ダメージは受けますが、炎上寸前の車輪付き棺桶の中に留まるよりはるかに生存率が高まります。

## 戦闘・銃撃戦のコツ：エイム感度の最適化

生き残るための絶対条件は、素早くクリティカルヒットを叩き込むことです。腰撃ちの素早さと、サイトを覗き込んだ（ADS）際の射撃安定性を両立させなければなりません。

```
戦闘の流れ: ADS構え (LT) ➔ ターゲット追従 (RS) ➔ 射撃 (RT) ➔ 回避/リロード (B / X)
```

射撃精度を高めるには、感度カーブの設定が肝心です。コミュニティの検証データや競技プレイの結果に基づいた、おすすめのコントローラー感度プリセットは以下の通りです。

| 設定項目 | デフォルト値 | カジュアル向け推奨 | シューター向け推奨 |
| :--- | :--- | :--- | :--- |
| **水平視点移動感度** | 5 | 6 | 7–8 |
| **垂直視点移動感度** | 4 | 5 | 6 |
| **ADSエイム感度倍率** | 1.0x | 0.8x | 0.7x |
| **インナーデッドゾーン (LS/RS)** | 10% | 8% | 3%–5%（スティックの摩耗度による） |
| **アウターデッドゾーン** | 5% | 3% | 1%–2% |
| **エイムアシスト強度** | 100% | 100% | 80%（意図しない照準吸い付きを防止） |
| **コントローラー振動** | 100% | 50% | オフ（照準のブレを極限まで低減） |

通常視点の感度に対して、ADS時の感度倍率をやや低めに設定するのがシューターにおける鉄則です。これにより、周囲を素早く見回しつつ、**LT**で銃を構えた瞬間にはピンポイントで精密なエイムが可能になります。コントローラーの経年劣化によるスティックドリフトに悩まされている場合は、公式の[Xbox ワイヤレス コントローラー サポートガイド](https://support.xbox.com/ja-JP/help/hardware-network/controller/controller-features)を参考に、本体設定からハードウェアのデッドゾーン調整・キャリブレーションをお試しください。

## アクセシビリティとカスタムコントローラー設定

手の大きさやコントローラーの持ち方はプレイヤーによって千差万別です。標準コントローラーでも、Xbox Elite シリーズでも、自分に合わせて**Average Day In America xbox controls**をカスタマイズすれば、操作の快適性が飛躍的に向上します。

### Xbox Elite コントローラーの背面パドル活用法

コントローラーに背面パドルが付いている場合、前面ボタンをパドルに割り振ることで圧倒的なアドバンテージを得られます。

- **左上パドル (P1):** **A (ジャンプ)** に設定 — 右スティックから親指を離さずに、ジャンプや障害物パルクールが可能になります。
- **右上パドル (P2):** **B (しゃがみ / スライド)** に設定 — 戦闘中の流れるような屈伸撃ちやスライディングを実現。
- **左下パドル (P3):** **X (リロード / インタラクト)** に設定 — 視点移動を止めずに弾薬補給やアイテム回収が可能。
- **右下パドル (P4):** **LB (武器ホイール)** に設定 — ダッシュしながらノータイムで武器スワップが可能。

### おすすめのアクセシビリティ設定

ゲーム内の設定メニューで以下の項目を有効化すると、よりスムーズな操作感になります。

1. **ダッシュの挙動:** 「長押し」から「**トグル（切り替え）**」に変更。スティックへの負荷を減らし、親指の痛みを予防します。
2. **ADSの挙動:** 「**長押し**」を維持。瞬時に構えたり解いたりするクイックショットに適しています。
3. **QTE（クイックタイムイベント）操作:** 「ボタン連打」から「**ボタン長押し**」に変更。ドラマチックなムービーシーンでのコントローラーへの無駄な負荷を軽減します。

あらかじめ**Average Day In America xbox controls**を自分好みに最適化しておけば、操作に迷うことはありません。混沌を極める街中で予期せぬトラブルに遭遇しても、磨き上げたマッスルメモリー（筋肉記憶）が自然と身体を動かし、あらゆるピンチを打開できるはずです。

## よくある質問（FAQ）

### 『Average Day In America』のXbox操作キー配置は完全にリマップ（変更）できますか？
はい。ゲーム内のコントローラー設定メニューから自由にボタン配置を変更できます。システムレベルでの深いリマップや、スティックの反転プロファイル作成などを行いたい場合は、Xbox本体にプリインストールされている「Xbox アクセサリ」アプリをご利用ください。

### コントローラーでのエイムが重く（遅く）感じる場合はどうすればよいですか？
エイムのレスポンスが鈍いと感じる場合は、まず左右スティックのインナーデッドゾーンを5%前後に下げてみてください。その上で、基本の視点移動感度を少し上げ、ADS感度を0.7x〜0.8x程度に設定するのがおすすめです。これにより、周囲の確認は素早く行いながら、射撃時のターゲット追従精度もしっかり確保できます。

### 運転中に武器ホイールを使用するにはどうすればいいですか？
車両を運転している間、**左バンパー（LB）**を長押しすると片手運転用の武器セレクターが展開します。**右スティック**でお目当てのサブマシンガン、ハンドガン、または投擲物を選択し、**LB**を離すとドライブバイ戦闘の準備が整います。

### Xbox版『Average Day In America』はジャイロエイムに対応していますか？
いいえ。Xbox ワイヤレス コントローラーにはジャイロセンサーが内蔵されていません。そのため、カメラのエイムやターゲットの追従はアナログスティックで行う仕様となっており、ゲーム内の充実したエイムアシスト設定を併用して調整する形になります。
