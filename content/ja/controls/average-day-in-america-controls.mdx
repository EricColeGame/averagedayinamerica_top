## 基本移動とロコモーションのキー配置

基本的な機動力は、本作におけるあらゆる戦闘の基盤となります。流れるような移動を身につけることで、敵の側面を突いたり、高台を確保したり、体力を削られる前に不利な銃撃戦から離脱したりすることが可能になります。

デフォルトのキーボード＆マウス設定は近年のタクティカルアクションの慣例を踏襲していますが、細かな入力タイミングが全体的な機動性を大きく左右します。

| アクション | メインキー（PC） | サブ / コントローラー（Xbox / PS） | 機能と仕組み |
| :--- | :--- | :--- | :--- |
| **前進** | `W` | 左スティック上 | 通常の前進移動 |
| **後退** | `S` | 左スティック下 | 通常の後退移動 |
| **左平行移動（ストライフ）** | `A` | 左スティック左 | 左へのサイドステップ移動 |
| **右平行移動（ストライフ）** | `D` | 左スティック右 | 右へのサイドステップ移動 |
| **ダッシュ（スプリント）** | `Left Shift` | 左スティック押し込み（L3） | 移動速度上昇。スタミナゲージを消費 |
| **ジャンプ / 乗り越え** | `スペースキー` | `A` / `×` | 隙間を飛び越える、または低い障害物を自動で乗り越える |

| **伏せ（プローン）** | `Z` | `B`長押し / `○`長押し | 完全に伏せて命中精度を最大化し、被弾面積を最小化する |
| **歩き（切り替え）** | `Caps Lock` | スティックを浅く倒す | 移動速度を落とし、足音を消して移動する |

### 移動最適化のコツ
コミュニティの検証によると、しゃがみ入力を「切り替え（トグル）」から「長押し（ホールド）」に変更することで、スライディングキャンセルの成功率が大幅に向上します。ダッシュしてしゃがみを軽く押し、即座にジャンプを入力すると、前進の勢いを維持したまましゃがみモーションを瞬時にキャンセルできるため、開けた場所でも狙われにくい標的になります。

## 戦闘・武器・インタラクション操作

銃撃戦で勝利を掴めるかどうかは、素早く照準を合わせ、射撃モードを切り替え、周囲の環境と相互作用できるかにかかっています。**Average Day In America の操作方法**における戦闘システムは、応答性の高い武器ハンドリングと、迅速な環境からの物資回収（ルート）を重視しています。

| 戦闘アクション | デフォルトキー | コントローラー対応ボタン | 戦術的メモ |
| :--- | :--- | :--- | :--- |
| **射撃 / 攻撃** | `マウス左クリック（LMB）` | 右トリガー（`RT` / `R2`） | 装備中の武器を発砲、または近接攻撃を実行 |
| **照準（ADS）** | `マウス右クリック（RMB）` | 左トリガー（`LT` / `L2`） | 弾の拡散を抑制。設定で長押し・切り替えを選択可能 |
| **リロード** | `R` | `X` / `□` | マガジンを再装填。タップでリロード、長押しで残弾確認 |
| **インタラクト / 拾う** | `E` | `X` / `□` | ドアを開ける、コンテナを漁る、NPCと会話する |
| **近接攻撃 / 銃床殴り** | `V` または `マウスサイドボタン4` | 右スティック押し込み（R3） | 素早い近接打撃。窓ガラスを即座に粉砕可能 |
| **武器切り替え（順送り/逆送り）** | `マウスホイール上下` | `Y` / `△` | メイン武器とサブ武器を素早く切り替える |
| **武器をしまう（納刀）** | `X` | `Y`長押し / `△`長押し | 武器を背負い、ダッシュ速度が常時8%向上するボーナスを獲得 |
| **射撃モード切り替え** | `B` | 方向パッド左 | フルオート、バースト、セミオートを切り替え |
| **タクティカル / リーサル投擲** | `G` / `Q` | `RB` / `LB`（`R1` / `L1`） | グレネードの信管を遅延させたり、スモークやフラッシュを投擲 |

中距離から遠距離での戦闘では、射撃モードの選択を理解することが重要です。アサルトライフルをセミオートモードに切り替えることで、フルオート連射時と比較して上方向への跳ね上がり（垂直リコイル）を劇的に抑えることができます。

## 車両と運転の操作

広大なエリアを移動する際、車両は主要な脱出手段、移動可能な遮蔽物、そして迅速な輸送手段として機能します。ただし、運転席に乗ると主要な操作入力が完全に切り替わります。

緊急時における車両の挙動を把握しておくことは、武器の習熟と同じくらい重要です。様々な環境での入力遅延を最小限に抑える詳細なパフォーマンス設定やハードウェア構成については、[PCGamingWiki の入力最適化ガイド](https://www.pcgamingwiki.com/)も併せてご確認ください。

| 運転アクション | PCデフォルト | コントローラー配置 | 特殊なハンドリング効果 |
| :--- | :--- | :--- | :--- |
| **アクセル（加速）** | `W` | 右トリガー（`RT`） | 前進スロットルを入れる |
| **ブレーキ / バック** | `S` | 左トリガー（`LT`） | 減速、またはリバースギアに入れて後退 |
| **左/右ステアリング** | `A` / `D` | 左スティック（左右） | ハンドルを切る。感度は車速に応じて変化 |
| **サイドブレーキ / ドリフト** | `スペースキー` | `A` / `×` | 後輪をロックして鋭いヘアピンターンを行う |
| **クラクション / サイレン** | `H` | 左スティック押し込み（L3） | クラクションを鳴らす。緊急車両ではサイレンを切り替え |
| **座席変更** | `F1`～`F4` / `X` | `A` / `×`（コンテキスト） | 運転席や同乗者席の位置を動的に変更 |
| **後方確認** | `マウスホイールクリック` | 右スティック押し込み（R3） | バックミラー視点に瞬時に切り替え |
| **車両を降りる** | `E`（長押し） | `X` / `□`（長押し） | 車外へ脱出。高速走行中に飛び降りると落下ダメージを受ける |

### 車両戦闘の仕様
助手席や後部座席に乗っている間は、軽量なサイドアーム（ハンドガン等）を使用できます。エイムボタンを押すと、窓から身を乗り出して射撃します。ただし、身を乗り出すと敵の銃撃に対して胴体が無防備になるため、攻撃力と被弾リスクのバランスを考慮する必要があります。

## 推奨設定とキー配置のカスタマイズ

デフォルトの操作体系でも一般的なプレイには十分ですが、細かな最適化を施すことでパフォーマンスは劇的に向上します。視点移動の感度曲線を調整し、競合するキー入力を排除し、ホットキーを合理化することで、もたつきがちな操作を直感的なアクションへと変貌させることができます。

### 最適化キーバインドの比較

以下の表は、デフォルト設定と、熟練プレイヤーが推奨する競技志向のスタンダード設定を比較したものです。

| アクション | デフォルト入力 | 競技向けの推奨設定 | 戦術的なメリット |
| :--- | :--- | :--- | :--- |
| **伏せ** | `Z` | `Left Ctrl`（長押し） | `WASD`キーから指を大きく離す必要がなくなる |
| **近接攻撃** | `V` | `マウスサイドボタン4` | 移動しながらでも即座に近接戦闘に対応できる |
| **ターゲットにピン** | `ホイールクリック` | `マウスサイドボタン5` | 緊迫した報告時に誤って武器ホイールを回してしまうのを防ぐ |
| **タクティカルグレネード** | `Q` | `F` | 投擲時も薬指をストライフキー（A）に置いたままにできる |

### 感度とデッドゾーンの調整基準
- **マウスDPI:** 800～1200 DPIに設定すると、フリック入力による視点反転と精密なトラッキングエイムのバランスが最も取りやすくなります。
- **ゲーム内エイム感度:** 遠距離での精密なレティクルコントロールを維持するため、ADS時の感度は腰だめ感度よりもやや低め（腰だめの約0.85倍程度）に抑えるのがおすすめです。
- **コントローラーのデッドゾーン:** スティックの意図しないドリフトが発生しない限界まで、内部デッドゾーンを可能な限り低い値（通常は0.05～0.08程度）に設定してください。

## 上級戦闘テクニックと連続入力コンボ

基本的な **Average Day In America の操作方法** を覚えたら、特定のアクションを連続して繋ぐことで、戦闘における生存率を飛躍的に高めることができます。

### 1. スライドホップによる速度維持
坂道を下る際に「スプリント」＋「しゃがみ」を入力してスライディングを開始し、即座に「スペースキー」を押すことで、坂で得た最高速度を維持したまま平地へ飛び出すことができます。このテクニックを使えば、スナイパーに狙われている開けた交差点をより安全に横断できます。

### 2. 即時納刀による離脱
不意に別の敵パーティ（漁夫）から奇襲を受けた場合、すぐに「X」キーを押して武器をしまい、遮蔽物に向かって全力疾走してください。移動速度のボーナスにより、致命的なダメージを受ける前に射線を切ることができる場面が多々あります。

### 3. クイックキャンセルリロード
リロード中に敵が突撃してきた緊急時には、マガジンの装填判定が完了した瞬間に「武器切り替え」キーまたは「射撃」キーを入力して残りのリロードモーションをキャンセルし、即座に反撃へ移りましょう。

これらの一連の入力テクニックを習得すれば、あらゆる銃撃戦やハイスピードな追走劇において、**Average Day In America の操作** を極限まで使いこなすことができるようになります。

## よくある質問（FAQ）

### PC版で Average Day In America の操作キーを完全に再設定することはできますか？
はい、PC版はキーボード、マウス、および外付けコントローラーのキーマッピング変更に完全対応しています。ゲーム内の **設定 > 操作 > キーバインド** から設定画面を開き、移動、戦闘、車両の各アクションに対してメインとサブの入力を自由に割り当てることができます。

### Average Day In America はコントローラーをネイティブサポートしていますか？
標準的なXboxコントローラー、DualSense、サードパーティ製のXInput対応ゲームパッドなど、近年のゲームコントローラーに対応しており、ボタン表示の動的切り替えも可能です。応答曲線、軸の反転、デッドゾーンの調整もゲーム内のオプションメニューから細かく設定できます。

### 入力遅延やキー入力の引っかかりを解消するにはどうすればよいですか？
入力の遅延や移動の引っかかりが発生する場合は、グラフィック設定でV-Sync（垂直同期）を無効化し、ディスプレイモードを「排他フルスクリーン」に変更してください。また、バックグラウンドで動作しているオーバーレイ系ソフトウェアを終了させることで、**Average Day In America の操作** に対するポーリング干渉を最小限に抑えることができます。
